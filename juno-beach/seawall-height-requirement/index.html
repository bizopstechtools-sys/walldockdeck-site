Juno Beach · Palm Beach County

How high does a seawall have to be in Juno Beach?

No minimumset in local code

Juno Beach's code has no seawall section and sets no seawall height. Seawalls appear only in the floodplain rules and the fertilizer setback.

Source: Town of Juno Beach Code of Ordinances (Municode), Ch. 7 Flood Regulations, Sec. 7-27; Ch. 12 Sec. 12-155 · Verified 2026-10

The detail

MinimumNone found
FloodplainIn Zone V, bulkheads and seawalls need authorization from the appropriate federal, state or local authority, must stand clear of, and unattached to, buildings, and need a qualified registered design professional's analysis of floodwater diversion and wave run-up and reflection; no elevation is set - Sec. 7-27(h) (Ord. No. 687, 2016)
FertilizerNone within 10 ft of the top of a seawall or bulkhead, or 3 ft using a deflector shield, drop spreader or liquid applicator with a visible, sharply defined edge; new plantings may be fed in that zone only for 60 days, starting 30 days after planting - Sec. 12-155 (Ord. No. 736, 2021)
What the code coversSearching the town code for seawall and bulkhead returns only the floodplain and fertilizer sections; the code has no seawall, bulkhead or dock chapter
